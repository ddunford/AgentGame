# Resume work

Owner: producer. Read the game's instructions/adapter, its authoritative task queue and linked active plan, then the framework AGENTS.md, ROSTER.md and relevant workflow. Resolve paths from the declared game/framework roots, not an assumed .claude directory.

Check the available controls before claiming runtime access: a supported computer-control surface or engine API can be sufficient; MCP/Remote Control are not mandatory. Read current saved assets/evidence as needed and reconcile stale queue/state claims.

State the milestone, last verified outcome, active task, pending verification, actual blocker or reserved decision and next ready action. Preserve settled scope. Use team-execute for multi-role work and pass the game adapter to delegates. If a capability is absent, name the affected test rather than imply the entire game cannot be worked on.
