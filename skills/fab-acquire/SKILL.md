# Acquire a Fab asset

Owner: tech-artist. Read guides/tooling-ue.md and the game’s asset/spend policy. No BrowserToolset, Playwright MCP or other transport is required.

1. Research the exact listing with available supported controls. Verify title, price, licence and engine/platform compatibility; record the source and date. A free filter alone does not prove suitability or rights.
2. Use the requested editor Fab panel or approved browser route. Confirm the correct account/project. If sign-in needs the user, prepare the selection and identify that specific dependency.
3. Acquire only within existing authorization. Paid purchases require the owner’s approval. Resolve unclear licence terms before importing for game use.
4. Follow the listing’s actual installation/import flow, save and verify assets on disk and in the project. Different delivery types may install differently; a completed download is not a usable-asset test.
5. Hand off to ingest-asset for the declared project content root, collision, budgets, dependency and provenance checks. Acquisition is not placement acceptance.
